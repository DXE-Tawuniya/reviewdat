# Tabs

A segmented pill switcher for 2–4 views of the same list (All / Pending / Done).

- The selected tab is a `brand` pill with `on-brand` text on a `surface-subtle` track.
- Labels are one word when possible; don't use tabs for more than 4 options.
- **The consumer provides:** `items` (`value` + `label`), and `value`/`onChange` to control it.
